# 🌍 Site de Turismo

Projeto de uma página de turismo desenvolvido como atividade da **Rocketseat**, para praticar HTML e CSS.

## 🛠️ Tecnologias

- HTML
- CSS

## 📚 Aprendizados

- Estruturação de páginas com HTML.
- Estilização com CSS.
- Uso de imagens, fontes e espaçamentos.

## 🚀 Como visualizar

Baixe o projeto e abra o arquivo `index.html` no navegador.
